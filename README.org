#+TITLE: Advent of Lisp
#+SUBTITLE: Solutions to Advent of Code puzzles in Common Lisp

* Summary

This repository contains solutions to [[https://adventofcode.com/][Advent of Code]] puzzles, written in Common Lisp. Specifically, SBCL is used to check the results.

This repository is educational, to learn CL by using the puzzles as a motivation. Also, I like to benchmark these solutions against solutions in other programming languages ...
